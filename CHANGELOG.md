## [1.0.0] - 2026-09-19

### Added
- Initial release for Windows platform
- Expense tracking with categories
- Budget management system
- Financial goals tracking
- Basic spending analytics
- Offline-first architecture
- SQLite database with encryption
- Recurring transaction support
- Calendar view for transactions
- Data export functionality
- Dark/Light theme support
- Financial health calculator

### Security
- Hardware-backed encryption (Windows Credential Manager)
- Local-only data storage
- No external data transmission
- Secure database implementation

### Platform Support
- Windows 10+ (x64)
- Android (configured for future deployment)
- iOS (configured for future deployment)

### Known Limitations
- Windows only (initial release)
- No cloud sync
- Manual updates required
- No code signing (security warning on download)
